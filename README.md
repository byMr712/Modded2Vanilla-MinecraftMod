# MrModded2Vanilla

Клиентский мод для Minecraft, обеспечивающий комфортную и стабильную игру со сборками модов при подключении к ванильным и сетевым серверам.

## О моде

Modded2Vanilla позволяет играть с любимыми контентными модами (на новые блоки, предметы, существ, броню и декорации) в одиночной игре и без проблем заходить на обычные многопользовательские серверы (включая Vanilla, Paper, Purpur, Spigot, Realms и серверы через ViaFabricPlus) без необходимости каждый раз удалять моды или переключать профили в лаунчере.

## Какую проблему решает мод

Когда вы устанавливаете моды с новым контентом, они добавляют в игру кастомные параметры существ, блоков и предметов. При входе с такой сборкой на обычный сервер возникали сбои:
- Игра могла вылетать при появлении мобов или игроков из-за несовпадения внутренних параметров.
- Могли происходить случайные отключения при получении сервером незнакомых сигналов или данных предметов.
- Сторонние эффекты или нестандартные модели могли приводить к ошибкам отображения.

Modded2Vanilla автоматически берет на себя защиту подключения и предотвращает подобные ошибки.

## Возможности

- Защита синхронизации существ и игроков: предотвращает вылеты игры при загрузке мобов и других игроков на сервере.
- Безопасное отображение анимаций и моделей: при сбое отображения кастомных косметических элементов или моделей игра не закрывается с ошибкой, а продолжает стабильно работать.
- Умная защита сетевого соединения: блокирует отправку лишних сетевых запросов, которые сервер не ожидает получить, предотвращая случайные кики античитом.
- Безопасная работа с предметами: при перемещении вещей в творческом режиме убирает несовместимые скрытые свойства перед отправкой на сервер.
- Защита от сбоев звуков и частиц: фильтрует некорректные звуки и визуальные эффекты, предотвращая разрыв связи с сервером.
- Сохранение канонических блоков: гарантирует, что на сервере все стандартные блоки отображаются строго правильно.
- Полная совместимость с ViaFabricPlus: стабильная работа при игре на серверах любых других версий.
- Понятное оповещение в логе: если мод заметил несовместимость со сторонними модами и применил исправление, он один раз выведет аккуратное уведомление со списком затронутых файлов.

## Режимы работы

Мод работает полностью автономно и не требует ручной настройки:

- В одиночной игре: изоляция отключена, все ваши моды, блоки, предметы и механики работают в полном объёме.
- На обычном/ванильном сервере: автоматически активируется изоляция ванильных механик и фильтрация сетевых пакетов, обеспечивая чистое подключение без вылетов и сбоев.
- На сервере с модами (Fabric, NeoForge, Forge): мод автоматически определяет поддержку модов сервером, снимает ванильные ограничения и позволяет модовым каналам и механикам работать штатно.

## Установка

1. Скачайте подходящую версию (Fabric или NeoForge) со страницы [GitHub Releases](https://github.com/byMr712/Modded2Vanilla-MinecraftMod/releases).
2. Требования в зависимости от загрузчика:
   - Для Fabric: Fabric Loader и Fabric API.
   - Для NeoForge: загрузчик NeoForge.
3. Поместите скачанный `.jar` файл в папку `mods`.
4. Запустите игру.

## Сборка из исходников

Для сборки проекта выполните команду в терминале:
```bash
./gradlew build
```
Собранные файлы для обоих загрузчиков (Fabric и NeoForge) будут находиться в папке `build/libs` (и при наличии папки синхронизируются в `Documents/MrModded2Vanilla_all_builds`).

## Автотестирование совместимости

Для быстрой автоматической проверки корректной изоляции модов и подключения к серверу предусмотрены Gradle-задачи:
- **Fabric:**
  ```bash
  ./gradlew testFabric
  ```
- **NeoForge:**
  ```bash
  ./gradlew testNeoForge
  ```
- Вы также можете указать любой сервер для проверки:
  ```bash
  ./gradlew testFabric -Pserver=example-server.com
  ./gradlew testNeoForge -Pserver=example-server.com
  ```
- **Примечание для NeoForge:**
  Для запуска `./gradlew testNeoForge` на стороннем ПК требуется установленный ATLauncher с инстансом под целевую версию Minecraft (по умолчанию `Minecraft1214withNeoForge`), либо переопределение пути к директории ATLauncher через переменную окружения `ATLAUNCHER_DIR`.
- **Тестирование собственных модов:**
  Поместите любые сторонние `.jar` файлы модов в соответствующие папки:
  - Для Fabric: в папку `test_mods/fabric/`
  - Для NeoForge: в папку `test_mods/neoforge/`
  При запуске автотестов они автоматически скопируются в тестовый клиент и проверятся на подключение к серверу. Все `.jar` файлы в этих папках внесены в `.gitignore` и не попадут в коммит.
- Запуск полных 10-раундовых тестов со сложными модами:
  - Fabric: `pwsh -File scripts/test_all_fabric_rounds.ps1`
  - NeoForge: `pwsh -File scripts/test_all_neoforge_rounds.ps1`
